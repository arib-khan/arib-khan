## 🚀 Selected Projects

### 🐱 [MEOW-Island](https://github.com/arib-khan/MEOW-Island)
A React Native Expo Android project exploring a customizable Dynamic Island-style overlay, with activity and utility features.

### 🛰️ SatQuery AI
A satellite imagery analysis and visual question-answering concept using Python, Streamlit, FastAPI, and geospatial tooling such as GDAL, Rasterio, and GeoPandas.

### 📄 TrueDoc
A document management and verification platform built with Django REST Framework, featuring multi-tenant organization support, role-based access control, QR-based verification, and bulk document generation.

### 🧾 RetailMitr
A billing and inventory management application concept with product inventory, barcode generation, billing, low-stock alerts, and PDF sales reports.

### 🛡️ Cyber Evolve — Predict Live Network
An experimental network-traffic monitoring and forecasting project using packet capture data and machine-learning models to explore threat detection and traffic prediction.
